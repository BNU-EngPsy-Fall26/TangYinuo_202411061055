信号与噪音的操作性定义

信号检测论的第一步，永远是把"信号"和"噪音"说清楚：它们不是两种东西， 而是同一个观察量在两种不同来源下的取值分布。你看到的每一帧瀑布图都不可能告诉你答案， 只能给出"证据强度"。

实验参数设置

50%

试次中"有目标"的比例。它不改变你的辨别力，却会显著改变划算的判定标准。

1.5

决定线谱相对噪声的强度。d′ 越小，两条分布重叠越多，越难分辨。

40 试次

试次越多，统计越稳。作业要求每局不少于 20 试次。

2.5 s

瀑布图扫描的时长。扫描结束画面即冻结，此时才开放作答。

    把 d′ 和 c 拖起来看

    这里的每一条曲线都是公式算出来的，不是画上去的。拖动滑块，观察 辨别力（两个分布的距离）和判定标准（那根竖线）分别改变了什么。

    参数

    1.5

    两个分布均值之间的距离。调大它，两条曲线分开。

    0.00

    c > 0 保守（少报"有"），c < 0 宽松（多报"有"）。

    50%

    影响最优判定标准 c*，不影响 d′。

    支付矩阵（相对价值）

    两个分布与判定标准

    橙色曲线是噪音分布 N(0,1)，青色曲线是信号分布 N(d′,1)。竖线是判定标准： 落在它右边的"噪音"会被误报（橙色阴影），落在它右边的"信号"会被击中（青色阴影）。 紫色虚线是给定先验与支付矩阵下的最优标准 c*。

    ROC / z-ROC

    固定 d′、把所有 c 走一遍，得到的轨迹就是 ROC。等方差模型下， 换到 z 坐标后它是一条斜率 1 的直线，纵轴截距恰好等于 d′。
